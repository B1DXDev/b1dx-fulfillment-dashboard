TUNING Context-load & Speed — วันนี้ (060–065)

ตัด context bloat = ตัวคูณ latency/token ต่อ build · quality gate ไม่ลด (verified ที่ agent surface)

060
Per-role reading — เลิก "ทุก agent อ่านครบ 5 ไฟล์" → matrix ต่อ role. orchestrator/ba → sonnet บน route เบา. ui-tester −1,293/spawn
061
Prompt slim — ย่อ 4 agent prompt ยักษ์ → core + on-demand appendix. −1,388 บรรทัด (−25%)
062
Contract → code — reconcile pagination {items,page,pageSize,totalCount} + error httpstatuses.com + errorCode ให้ตรง code จริง (doc 2 เวอร์ชันขัดกัน). ปิด FE/BE integration bug
063
FE/BE split + gate — clean-code แยก C#/TS/Go · §13 query-cache → fe-design · api/fe-design header on-demand. reviewer −106KB/single-stack PR · coder −250/load
064
MICRO tier — sub-tier ของ FAST สำหรับ bug-fix/ui-only/chore-docs ที่ risk=LOW + effort XS/S + confidence≥0.85 + ไม่แตะ security surface: ข้าม UI Tester (scaffold+run) + Reviewer subagent ทั้งคู่ — coder self-verify + self-review (/review --effort medium) แทน. เพิ่ม carve-out skip security-reviewer สำหรับ non-migration HIGH ที่ไม่ได้มาจาก 4 surface trigger (migration + surface-trigger HIGH ยังบังคับเสมอ). agent hand-off น้อยลง ต่องานเล็กจริงๆ — quality gate (build/test/review) ไม่ถูกตัด แค่ไม่ hand-off เป็น subagent แยก
065
Gate dedup + risk-tier carve-outs — ลบ Plan Gate procedure ที่ restate ซ้ำ 2 ที่ (orchestrator.md ↔ workflow-protocol.md) + reading-list ที่ซ้ำใน 9 agent files, zero behavior change; แก้ plan-reviewer false-positive ("ไม่มี" + เหตุผล ไม่ใช่ blank); cap investigator round + plan prose สำหรับ XS/S effort เท่านั้น. เพิ่มเงื่อนไข carve-out ใหม่ 4 จุด: bug-fix data-mutation MEDIUM→LOW (root cause เดี่ยว + regression test + confidence≥0.85), MICRO รับ sync-webhook, MICRO-M sub-tier (bug-fix effort M, confidence≥0.90, ≤2 repos, เก็บ incremental reviewer ไว้), Migration Risk Tiers (additive/reversible = MEDIUM ไม่บังคับ security-reviewer). ทุก carve-out เก็บ GATED human review + architect schema review + regression test ไว้ครบ — ตัดเฉพาะ ceremony ที่ซ้ำซ้อน ไม่ตัด gate ที่จับ bug จริง
