B1DX Order Status (OMS / FF / WMS) — Category Reference

รวม status ทุกระดับของ B1DX ไว้ตารางเดียว distinct ตาม Status + Category (ไม่แยกคอลัมน์ OMS/FF/WMS แล้ว — ชื่อกับ Category เดียวกันจากคนละ layer ถูก merge เป็นแถวเดียว) ใส่คอลัมน์ Category ด้วย taxonomy เดียวกับตาราง Lazada ด้านบน เพื่อให้เทียบแถวต่อแถวง่ายขึ้นตอน map — ส่งตารางนี้ให้ business/WMS ตรวจสอบแล้วช่วยยืนยัน Category ให้ตรงจริง (คอลัมน์หมายเหตุจะบอกไว้ถ้า code เลขไม่ตรงกันระหว่าง layer)

ความสัมพันธ์ระหว่าง field: OrderStatus (OMS) = สถานะหยาบที่ลูกค้า/มาร์เก็ตเพลสเห็น · FulfillmentSubStatus (FF) = sub-step ละเอียดของ Order Action Dialog (OAD) — เป็นคนละ field, orthogonal กับ OrderStatus (การกด action ใน OAD เขียนลง FulfillmentSubStatus เสมอ ไม่ใช่ OrderStatus โดยตรง — ดู ADR-002) · FrStatus = สถานะงานคลังต่อ 1 Fulfillment Request (อยู่ใน Order module ฝั่ง OMS แต่สะท้อนความคืบหน้าฝั่งคลัง) · WMS ระดับ pick/pack session ยังไม่มี enum อย่างเป็นทางการ (PickSession.Status string constants เท่านั้น — PackSession ไม่มี status field เลย) · ข้อควรระวัง: บาง code เลขซ้ำกันข้าม layer แต่ความหมายคนละเรื่อง (เช่น code 600 = Delivered ใน OMS แต่ = Returning ใน FF) — ดูคอลัมน์หมายเหตุของแถวนั้น ๆ
